Description of the proyect 
In this proyect it lets you to manage a diferente typs of animales saved in a CVS file.
You can also use filters to look for an specific type of animal depending on its caracterstics, it also has the option to add and save animals and its species.

# Structure of the proyect 
"main.py"  Principal logic ogf the program 
"animal.py" Definition of the Animal class and auxiliary functions for reading/writing CSV files.
"clases.csv"  Category of the animals
"zoo.csv" Data base of the animals and its caracteristics
